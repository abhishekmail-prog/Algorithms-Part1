# Module 1: Introduction to Algorithms

## What I learned

This module introduced me to the fundamentals of algorithms and why efficiency matters.

### Key ideas

- Algorithms are step-by-step procedures to solve problems.
- Different solutions to the same problem can have very different performance.
- We measure efficiency using time complexity and space complexity.
- Computer Science is not just about making code workk; its about making code efficient.

---

## Example

Problem:
Find whether a number exists in a array

Approach 1:
Linear Search

```cpp
for(int i = 0; i < n; i++) {
	if(arr[i] == target) {
		return true;
	}
}
```

Time Complexity:

O(N)

Reason:
In the worst case, we may scan the entire array.
